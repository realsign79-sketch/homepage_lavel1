### 1-3. 기술·UX 문제 (P1)

- 인코딩 **EUC-KR**. 2026년 기준으로 UTF-8이 아닌 것은 레거시 신호이고 공유/AI 파싱 시 깨질 위험이 있다.
- 폐쇄된 `googlecode.com` 스크립트 4개를 `http://`로 로드한다. 404가 나고, mixed content로 렌더링이 차단된다.
- jQuery 1.7.2(2012년), `document.write` 방식 로그 스크립트 → 성능(INP)과 보안에 불리하다.
- `user-scalable=no` → 확대를 막아 **접근성 위반**(KWCAG 2.2, WCAG 1.4.4).
- 로고와 메인 슬라이드 이미지에 `alt`가 없다. H1이 없다(메인 실페이지 기준).
- 푸터가 `width:730px`로 고정돼 있다. 카카오톡 버튼에 링크가 없고, 인스타그램 `<a>` 태그가 닫히지 않았다.
- 메인 문구가 "최고의 강사진", "정성껏 상담" 같은 **추상적 문구뿐**이다. 수강료, 기간, 합격률, 취업처 등 **검증 가능한 사실 정보가 없다**.
- title에 `★` 특수문자를 쓰고 있고, 메인과 서브의 title이 모두 같다.
- 이메일(hanmail)이 평문으로 노출돼 스팸 수집 대상이 된다.
- 메타 설명의 **"취업보장"** 표현은 학원법상 과장광고 소지가 있다. "취업 연계", "취업 지원"으로 바꿀 것을 권장한다.

### 5-2. 과정 상세 `/courses/*` (템플릿 공통)

1. **요약 박스 (TL;DR)**: 기간, 수업 요일·시간, 수강료(또는 범위), 정원, 대상, 취득 자격증
2. 누구에게 맞는 과정인가
3. 주차별 커리큘럼 (표)
4. 시험 정보: 주관 단체, 필기·실기 구성, 도쿠 합격률
5. 수강료·결제·환불 규정 (학원법 준수 표기)
6. 이 과정 수료생 후기
7. 과정별 FAQ (3~5개)
8. CTA: 개강일 확인 + 상담

→ 스키마: `Course` + `CourseInstance` + `Offer` + `FAQPage` + `BreadcrumbList`

### 5-3. 자격증 가이드 `/license-guide` (필러 콘텐츠)

"애견미용사 자격증"이라는 키워드 자체를 잡는 **교과서형 페이지**다. 학원 광고가 아닌 중립 정보로 쓴다.
- 민간자격 구조(주관 단체별: 한국애견연맹(KKF), 한국애견협회(KKC) 등), 3급~사범 등급, 응시 조건, 시험 과목, 준비 기간
- 독학 vs 학원 vs 전문학교 비교표
- 업데이트 날짜 명시 + 출처 링크 → **AI가 가장 많이 인용하는 형태**

### 5-4. 원장 프로필 `/about/director`

- 경력 연표, 보유 자격(급수·발급기관), 심사위원·대회 수상 이력, 언론 노출, 강의 철학
- `Person` 스키마 + `sameAs`(인스타·블로그)
- 모든 칼럼의 **저자**로 연결된다. 2026 구글·AI 모두 "누가 썼는가"를 강하게 본다.

### 5-5. FAQ `/faq`

카테고리: 입학·수강료 / 자격증·시험 / 취업·창업 / 수업 운영 / 위치·시설. 초기 30문항을 목표로 한다.
답변 규칙: **첫 문장 40~60자 안에 결론**, 그다음 부연 설명. `FAQPage` 스키마를 붙인다.

### 5-6. 상담 `/contact`

- 모바일 **하단 고정 CTA 바** (전화 · 카톡 · 상담신청) → 전 페이지 공통
- 상담폼: 이름, 연락처, 관심 과정, 희망 시간대 + 개인정보 동의. 3필드 수준으로 최소화한다.
- 네이버 예약 / 네이버 톡톡 연동 여부를 검토한다.

## 6. SEO · AEO · GEO 적용 명세

### 6-1. 기술 SEO (기본기)

- [ ] 도메인 루트에서 직접 서비스, HTTPS 강제, `www` → non-www 통일
- [ ] 기존 URL 전부 **301 리다이렉트 매핑표** 작성 (`/bizdemo25235/business/business_1.php?tit=02&sub=01` → `/courses` 등). 쿼리스트링 매칭이 필요하므로 호스팅 선택 시 반영
- [ ] UTF-8, `lang="ko"`, 페이지별 고유 title(≤ 60자)·description(≤ 120자)
- [ ] canonical, Open Graph, Twitter card, 과정별 OG 이미지 자동 생성
- [ ] `sitemap.xml`(lastmod 정확히) + `robots.txt`
- [ ] 시맨틱 HTML (H1 1개, 논리적 heading 계층), 모든 이미지 `alt` 필수
- [ ] 이미지 AVIF/WebP + `srcset`, LCP 이미지 preload, 폰트 서브셋(Pretendard 가변 폰트)
- [ ] JS 최소화 (정적 HTML 우선) → 크롤러와 AI 봇 모두 **JS 없이 본문 전체를 읽을 수 있어야 한다**
- [ ] **네이버 서치어드바이저**, **Google Search Console**, **Bing Webmaster Tools** 등록 (ChatGPT 검색이 Bing 색인을 활용한다) + **IndexNow**

### 6-2. 구조화 데이터 (JSON-LD)

| 페이지 | 스키마 |
|---|---|
| 전역 | `EducationalOrganization` + `LocalBusiness` 병합(`@type` 배열): 이름, 주소, geo, 전화, 영업시간, `sameAs`, 로고 |
| 전역 | `WebSite`, `BreadcrumbList` |
| 과정 | `Course`, `CourseInstance`(개강일, 수업 방식), `Offer`(가격) |
| 원장·저자 | `Person` (`jobTitle`, `hasCredential`, `award`, `sameAs`) |
| FAQ | `FAQPage` |
| 칼럼 | `Article` (`author`, `datePublished`, `dateModified`) |
| 후기 | `Review` / `AggregateRating` → ⚠ 자사 사이트 자체 리뷰는 구글 별점 리치결과 대상이 아니므로, 마크업은 하되 기대치는 낮춘다 |
| 갤러리 | `ImageObject` (캡션 포함) |

### 6-3. AEO (Answer Engine Optimization): "답"이 되기

- 모든 핵심 페이지 상단에 **요약 박스(TL;DR)**: 질문형 H2 + 즉답 문단
- H2와 H3를 **실제 검색 질문 문장**으로 작성한다 (네이버 자동완성, 지식iN, 구글 "관련 질문"에서 수집)
- 표·리스트·단계(Step)를 적극 활용한다. AI와 스니펫이 가장 잘 추출하는 형태다
- 수치는 문장 안에 넣는다: ✗ "높은 합격률" → ✓ "2025년 3급 실기 응시생 ○명 중 ○명 합격(○%)"

### 6-4. GEO (Generative Engine Optimization): AI가 "인용"하게 만들기

1. **엔티티 일관성 (가장 중요)**: 상호, 주소, 전화(NAP)를 **네이버 플레이스·카카오맵·구글 비즈니스 프로필·인스타·블로그·홈페이지에서 글자 하나까지 동일**하게 맞춘다. AI는 여러 출처가 교차 확인되는 정보를 신뢰한다.
2. **AI 크롤러 허용**: `robots.txt`에서 `GPTBot`, `OAI-SearchBot`, `ChatGPT-User`, `ClaudeBot`, `Claude-SearchBot`, `PerplexityBot`, `Google-Extended`, `Yeti`(네이버), `Bingbot`을 명시적으로 허용한다.
3. **`/llms.txt`**: 학원 개요, 과정 요약, 핵심 사실, 주요 페이지 링크를 마크다운으로 정리한다.
4. **팩트 페이지**: "도쿠애견미용학원 한눈에 보기" 섹션을 둔다(설립연도, 등록번호, 위치, 과정, 정원, 합격 실적). AI가 그대로 인용할 수 있는 형태로 쓴다.
5. **신선도**: 모든 콘텐츠에 `dateModified`를 표시하고, 개강일정·실적을 분기마다 갱신한다.
6. **외부 언급(Off-site)**: 네이버 블로그 칼럼 ↔ 홈페이지 원문을 상호 링크한다. 대회 수상 기사와 지역 커뮤니티(맘카페, 당근) 언급도 확보한다. AI는 자사 사이트보다 **제3자 언급**을 더 신뢰한다.
7. **네이버 AI 브리핑 대응**: 네이버는 자사 생태계(블로그·플레이스·지식iN) 비중이 크다. 따라서 **홈페이지는 원본 허브, 네이버 블로그는 확산 채널**로 역할을 나눈다. 플레이스 정보도 완성도 100%로 채운다.
8. **측정**: 월 1회 주요 질의 20개를 ChatGPT, Perplexity, Google AI Mode, 네이버에서 점검해 도쿠 언급 여부를 기록한다(엑셀 트래킹). GA4에서 AI 리퍼러(chatgpt.com, perplexity.ai 등) 채널을 분리한다.

## 7. 디자인 방향 (2026 트렌드)

| 트렌드 | 적용 |
|---|---|
| **진정성 있는 실사 비주얼** | 스톡 이미지 대신 실제 수업·학생·작품 사진과 짧은 영상을 쓴다. AI 생성 이미지 범람에 대한 반작용으로 '진짜'가 신뢰 요소가 됐다 |
| **벤토 그리드** | 과정·실적·후기를 카드 모듈로 배치 → 모바일에서 자연스럽게 스택 |
| **대담한 타이포그래피** | Pretendard Variable, 큰 헤드라인, 넉넉한 여백 |
| **절제된 모션** | View Transitions API 페이지 전환, 스크롤 연동 등장 효과는 `prefers-reduced-motion` 존중 |
| **따뜻한 컬러** | 기존 다크(#151515) 탈피. 크림/웜 베이지 바탕 + 포인트 컬러 1개(코랄 or 딥 그린). 다크모드 지원 |
| **모바일 퍼스트 + 엄지 영역 CTA** | 유입의 대부분이 모바일(인스타·네이버)이므로 하단 고정 상담 바 |
| **숏폼 임베드** | 인스타 릴스 / 유튜브 쇼츠의 미용 비포·애프터 영상 |
| **접근성 기본값** | KWCAG 2.2 / WCAG 2.2 AA: 대비 4.5:1, 키보드 탐색, 확대 허용 |

## 8. 기술 스택 (제안)

| 영역 | 선택 | 이유 |
|---|---|---|
| 프레임워크 | **Astro** (정적 생성 + 필요한 곳만 아일랜드) | 기본 출력이 순수 HTML이라 크롤러·AI 친화적이고, CWV 최상위 |
| 스타일 | Tailwind CSS v4 | 빠른 구현, 디자인 토큰 관리 |

| 호스팅 | Cloudflare Pages (+ Bulk Redirects로 쿼리스트링 301 처리) | 무료~저비용, 국내 속도 양호, 리다이렉트 유연 |
| 폼 | Cloudflare Worker → 이메일/카카오 알림톡 | 서버 없이 상담 접수 |
| 분석 | GA4 + 네이버 애널리틱스 + Search Console | AI 리퍼러 채널 분리 |
| 이미지 | Astro Image (AVIF/WebP 자동) | LCP 최적화 |

※ 도메인 DNS는 현재 호스팅사(fmcity/카페24 계열) 관리로 추정. 이관 권한 확인이 필요하다.

## 9. 마이그레이션 계획

1. 기존 사이트 전체 URL 목록 확보 (서버 로그 or 호스팅 관리자) → 301 매핑표
2. 기존 게시판(공지, Q&A, 갤러리) 중 **살릴 콘텐츠 선별**: 갤러리 사진과 FAQ는 재활용하고, 오래된 Q&A는 FAQ로 재가공
3. 신규 사이트 스테이징에서 검수 (크롤링 테스트, 스키마 검증, CWV 측정)
4. DNS 전환 → 즉시 서치어드바이저·GSC·Bing에 사이트맵 제출 + IndexNow 핑
5. 전환 후 4주간 404·색인 모니터링

## 11. 학원 측에 받아야 할 자료 (콘텐츠의 원천)

GEO/AEO는 **구체적 사실이 없으면 작동하지 않는다.** 아래 자료가 기획의 성패를 좌우한다.

- [ ] 개원 연도, 연혁, 왕십리점 운영 여부(현재 robots.txt에 흔적이 있음)
- [ ] 과정별 기간, 요일·시간, 정원, 수강료, 환불규정
- [ ] 발급 자격증 주관 단체(KKF / KKC / 기타)와 급수
- [ ] 연도별 합격 인원·합격률, 대회 수상 내역(대회명·연도·등급)
- [ ] 졸업생 취업처(샵명 공개 가능 여부), 창업 사례
- [ ] 원장 경력·자격·심사 이력·언론 노출
- [ ] 국비지원(내일배움카드) 지정 여부
- [ ] 실제 수업·시설·작품 사진, 짧은 영상 원본
- [ ] 수강생 후기(게재 동의)
- [ ] 카카오톡 채널 URL, 네이버 플레이스 URL, 구글 비즈니스 프로필 유무
- [ ] 도메인·호스팅 관리자 계정 접근 권한
- [ ] 현재 월 상담 건수(KPI 기준치)
